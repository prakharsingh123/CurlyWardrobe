# 👗 Clothing Brand Website

**A collaborative project by [Luna](https://github.com/xYulania) and [Bash](https://github.com/bashayernew)**  
*“Where fashion meets simplicity.”*

---

## 🚀 Project Overview

This website showcases a clothing brand, highlighting its collections, story, and contact details. It’s designed to be simple, elegant, and easy to browse, offering a clear view of the brand’s style and values.

---

  ## 🌟 Key Features

- 🖼️ **Stylish Product Display:**  
  Showcase the brand’s collections with clean layouts and high-quality images.

- 📝 **About the Brand:**  
  Share the story, mission, and vision behind the clothing brand.

- 📄 **Contact Information:**  
  Provide easy access to the brand's contact details and social media links.

- 🌐 **Responsive Design:**  
  Optimized for a seamless experience on desktop, tablet, and mobile devices.
